# 🌙 Lunar - สำหรับใช้บันทึกรายจ่าย

เว็บแอปพลิเคชันสำหรับคู่รัก รูมเมต หรือเพื่อนสนิท 2 คน ช่วยจดบันทึกค่าใช้จ่าย หารค่ากิน ค่าห้อง ค่าน้ำค่าไฟ พร้อมระบบคำนวณยอดสุทธิและปุ่มเคลียร์หนี้ในคลิกเดียว ออกแบบพิเศษสำหรับมือถือแนวตั้งใน **ธีมดวงจันทร์ (สีเหลือง ขาว ดำ สไตล์กระจกด้าน โปร่งใส)** ล็อกการเลื่อนของหน้าจอ 100dvh ไม่เลื่อนไปมา รองรับมาตรฐาน PWA และวันที่ไทย พ.ศ.

🌐 **GitHub Pages URL**: [https://bosu-nsoq.github.io/lunar/](https://bosu-nsoq.github.io/lunar/)

---

## ✨ คุณสมบัติของ Lunar

1. **บันทึกตามผู้ล็อกอิน**: ผู้ที่กดรหัส PIN เข้าสู่ระบบจะเป็นผู้บันทึกรายการโดยอัตโนมัติ
2. **วิธีหารเงิน**: เลือกแบบ `จ่ายคนละครึ่ง` หรือ `จ่ายเต็ม`
3. **ตรวจสอบก่อนบันทึก**: มีหน้าต่างป๊อปอัพสรุปรายการทั้งหมดให้ตรวจสอบก่อนกดยืนยันบันทึก
4. **เคลียร์รายการรอส่งหมดจด**: ล้างตะกร้ารอส่งและฟอร์มกรอกทันทีเมื่อบันทึกข้อมูล
5. **ซิงค์รหัสและชื่อผู้ใช้ข้ามเครื่อง**: เมื่ออัปเดตชื่อหรือรหัส PIN ในหน้าตั้งค่า ข้อมูลจะซิงค์ผ่าน Google Sheets ให้ทุกเครื่องใช้งานรหัสเดียวกัน
6. **ธีมดวงจันทร์ (Lunar Glassmorphism)**: สีดำ เหลือง ขาว สไตล์กระจกฝ้าโปร่งใส เรียบหรู
7. **ระบบเคลียร์หนี้**: แสดงมิเตอร์ยอดหนี้สุทธิ พร้อมปุ่มเคลียร์หนี้รีเซ็ตยอดเป็น 0
8. **ปฏิทินไทย พ.ศ. + เวลา**: แสดงผล วัน/เดือน/ปี พ.ศ. (`dd/mm/yyyy พ.ศ.`) แตะเลือกวันที่และเวลาได้ทันที
9. **หมวดหมู่แบบป๊อปอัพ**: แตะเพื่อเปิดเลือกไอคอนหมวดหมู่อย่างรวดเร็ว
10. **ล็อกหน้าจอนิ่งสนิท**: ล็อกความสูง `100dvh` เหมาะกับมือถือแนวตั้ง ไม่เลื่อนไปมา
11. **รองรับการแจ้งเตือนผ่าน LINE**: แจ้งเตือนเมื่อมีรายการรายจ่ายใหม่หรือการเคลียร์หนี้เข้ากลุ่ม LINE อัตโนมัติ
