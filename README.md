# 💸 DuoPay - เว็บแอปบันทึกรายจ่าย & เคลียร์หนี้สำหรับ 2 คน

เว็บแอปพลิเคชันสำหรับคู่รัก รูมเมต หรือเพื่อนสนิท 2 คน ช่วยจดบันทึกค่าใช้จ่าย หารค่ากิน ค่าห้อง ค่าน้ำค่าไฟ พร้อมระบบคำนวณยอดสุทธิและปุ่มเคลียร์หนี้ในคลิกเดียว ออกแบบพิเศษสำหรับมือถือแนวตั้ง (100dvh No-Scroll) เน้นไอคอนใช้งานง่าย รองรับมาตรฐาน PWA และวันที่ไทย พ.ศ.

🌐 **GitHub Pages URL**: [https://bosu-nsoq.github.io/nb/](https://bosu-nsoq.github.io/nb/)

---

## ✨ ฟีเจอร์หลัก (Features)

1. **บันทึกรายจ่าย 2 คน (Duo Split)**: สลับผู้จ่ายได้สะดวกรวดเร็ว เลือกว่าหารคนละครึ่ง (50:50) หรือจ่ายให้อีกฝ่าย 100%
2. **ปฏิทินไทย พ.ศ. + เวลา**: แสดงผล วัน/เดือน/ปี พ.ศ. (`dd/mm/yyyy พ.ศ.`) แตะเลือกวันที่และเวลาได้ทันที
3. **ระบบล็อกอินด้วย PIN 4 หลัก**: แยกผู้ใช้ 2 คน ปลอดภัย สามารถตั้งรหัส PIN และเปลี่ยนชื่อ/อวตารได้เอง
4. **เพิ่มได้หลายรายการก่อนกดส่ง (Batch Queue)**: แตะเพิ่มรายการเข้าตระกร้าสะสมยอด และกด **"บันทึกข้อมูลทั้งหมด"** ครั้งเดียว
5. **ระบบเคลียร์หนี้ (Settle Up)**: แสดงมิเตอร์สถานะหนี้ชัดเจนว่าใครต้องโอนให้ใคร พร้อมปุ่มเคลียร์หนี้รีเซ็ตยอดเป็น 0
6. **Mobile Portrait First (จอไม่เลื่อน)**: ล็อกความสูง `100dvh` เหมาะกับมือถือแนวตั้ง ไม่เลื่อนจอไปมา
7. **เน้นไอคอน (Icon-driven UI)**: หมวดหมู่อาหาร เครื่องดื่ม ของใช้ เดินทาง บิล บันเทิง ชัดเจน ไม่เน้นตัวหนังสือยาว
8. **พร้อมขึ้น GitHub Pages & PWA**: รองรับการติดตั้งลงหน้าจอโฮม iOS / Android เสมือนแอปแท้
9. **Dual Database**: ใช้งานออฟไลน์ผ่าน LocalStorage ทันที หรือเชื่อมต่อ Google Sheets ผ่าน Google Apps Script

## 📲 วิธีเปิดใช้งาน GitHub Pages (เพื่อเปิดผ่านลิงก์บนมือถือ)

1. เข้าไปที่หน้า Repository: [https://github.com/bosu-nsoq/nb](https://github.com/bosu-nsoq/nb)
2. ไปที่เมนู **Settings** -> **Pages** (เมนูด้านซ้าย)
3. ในหัวข้อ **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** และโฟลเดอร์ **/ (root)**
   - กด **Save**
4. รอระบบประมวลผลประมาณ 1-2 นาที คุณจะสามารถเข้าใช้งานแอปได้ทันทีผ่านลิงก์:  
   👉 **[https://bosu-nsoq.github.io/nb/](https://bosu-nsoq.github.io/nb/)**

## 📂 โครงสร้างไฟล์
- `index.html` — หน้าเว็บแอปหลัก (HTML5 + CSS + Vanilla JS)
- `manifest.json` — การตั้งค่า PWA & Web App Icons
- `sw.js` — Service Worker สำหรับทำงานออฟไลน์
- `Code.gs` — โค้ด Backend สำหรับ Google Apps Script (เชื่อม Google Sheets)
